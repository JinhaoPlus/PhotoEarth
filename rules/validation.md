# 验证、模拟器与真机

真机安装须遵守 [主约定](../AGENTS.md#真机安装授权)。项目脚本与用法见 [Scripts/README.md](../Scripts/README.md)。按版本和设备记录实际构建、签名、安装、启动及交互结果。

## 新版本归档门禁

确定发布版本和构建号后，在工程根目录执行 `Scripts/release_gate.py`。门禁先构建 Apple TV Release 主程序和 Top Shelf，再在独立模拟器上运行单元测试及关键遥控器流程。每轮保留 XCTest 结果包与报告。应用 target 的归档阶段核对当前源码、资源、测试、构建设置和通过记录。测试失败或发布输入变动时，修复后重跑门禁再归档。普通开发构建可照常进行。

完整命令、证据位置与专项验收边界见[项目验证技能](../.cursor/skills/verify-photoearth/SKILL.md)。涉及设备能力的改动按下方规则补验，并单独记录真机结果。

## 验证覆盖

测试不得依赖真实 iCloud Photos。为 Demo 准备包含虚构日期、经纬度和图片占位符的 fixture；真实 PhotoKit 集成通过设备手工测试。

- 无照片权限时应用不崩溃，并能进入说明或设置引导。
- 空照片库和没有 GPS 照片时显示明确空状态。
- 大量模拟资产的聚类不阻塞 UI，并具有确定性。
- 5 万张带位置照片的 SQLite 写入、摘要启动加载与世界视野限量查询均有自动化覆盖；视野查询结果数量必须受硬上限约束。
- 同一照片不会重复进入多个地点。
- 跨日期、跨城市、跨国家的排序稳定。

- iCloud 图片尚未下载时显示加载状态并允许重试。
- 快速切换照片不会显示过期请求结果。
- 本地索引删除或损坏后能自动重建。
- KVS 超时或暂时不可用不会阻塞地球展示。
- 遥控器可以到达并操作所有可交互元素。
- Reduce Motion 打开时不执行强烈的相机飞行和粒子效果。

- 离线地名未命中时保留真实坐标与访问，用匿名状态展示。单元和 UI 验证覆盖权限、可恢复空态、旧请求失效，以及固定范围、分页、计数和返回 Focus。
- 实体 Siri Remote 的落指、慢拖、快扫、抬手重落与持键，加上真机影像覆盖、帧时间、弱网 iCloud、Live Photo／视频、HDR 与音频，按具体任务选用真实 Apple TV 和授权图库复验。30 fps 是相机提交上限。

## 私有索引的本机负载验证

真机 SQLite 私有副本可用于只读的索引分布和查询负载验证；正确图片展示必须使用当前设备实际 PhotoKit 标识与其元数据，不能把真机标识映射为模拟器其他照片。2026-09-10 所见即所得要求覆盖此前图片替身策略。

- 启动一台已安装 PhotoEarth 的 Apple TV Simulator，在工程根目录执行 `Scripts/install_sqlite_fixture_in_simulator.sh`；脚本会校验数据库、备份模拟器旧索引，并复制到 App 沙箱的 `Library/Caches/PhotoEarth/travel-index-v3.sqlite`。
- 复制索引只适用于受控只读调试。正常启动的准备协调器会核对当前模拟器图库，不能承诺保持跨设备副本；负载查询优先直接使用独立数据库读取器。
- 所有构建都只按准确的 PhotoKit ID 请求图片，匹配不到时保留不可用状态。模拟器视觉验证使用 `--demo` / `--preparation-fixture` 的明确示例资源，或导入公开测试照片后扫描当前模拟器图库；不把替代图与真实索引坐标组合。
- 私有索引副本不进入截图、Git 或日志；原始照片、iCloud 下载性能及真实遥控器手感仍需真机验证。

索引样本位于 Git 忽略的 `.local-test-data/device-index/travel-index-v3.sqlite`。样本来源与计数记录在历史档案。
