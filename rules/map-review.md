# 地图回看与近景照片图钉

## 镜头、来源与返回

- 地图回看默认使用深色、平面、弱化强调的普通地图（`MKStandardMapConfiguration`，`.flat` / `.muted`），关闭 POI 与交通信息。地图／卫星切换放入 Play/Pause 唤出的原生 Liquid Glass 缩放工具条，保留当前镜头；主地球默认卫星，也提供同一地图／卫星切换。
- 最近到访、国家、分类城市和首页指定城市的照片墙提供「地图回看」。初始镜头按来源墙固定快照中的全部成员取景，进入后按当前地图画面显示可见照片。主地球和地图回看的当前画面墙用 Back 回到已存在的地图。来源照片墙保持原实例、固定范围、分页和滚动位置，返回恢复原照片 Focus。之后与普通滚动地球保持同一交互：进入即由方向键与完整触摸面直接移动，不再有「移动地图」状态。Play/Pause 唤出共享的缩放与底图工具条，Dock 内拖动继续有效，方向键只选择按钮。中键松开冻结当前地图并打开当前画面照片墙；Back 每次处理最上层：工具条收起回地图，详情退回当前画面墙，墙深处先回页首，墙在顶部退回地图，地图退回来源照片墙。

## 查询及原生图钉

- 地图回看的图钉和底部胶片不进入 Focus 图。近景地图停稳后，先展示本次严格投影通过的首批胶片，数量标注为预览数；全部候选处理完成后再同时交接图钉和准确总数。指定城市的近景读取在 SQLite 内限定到访成员，继续沿用同一游标完成统计。底部跟随当前画面读取完整照片集合，不固定为单次访问或城市，不以少量代表抽样冒充全部照片；冻结同一 SQLite 读取快照，以 RTree 每批最多读取 512 条候选、按原生投影严格筛选，停稳后仅一次 850 ms 防抖，准确计数与显示分页分离。胶片每批最多保留 48 条元数据并轮播屏幕可见部分，再按稳定时间倒序读取下一页；中键照片墙支持按需分页与跨页详情。新输入立刻使旧结果与过期请求失效。
- 地图回看收到拖动采样后立即失效旧投影；若松手、物理按键或工具条交接丢弃了尚未落帧的位移，必须重新安排当前静止地图的视野发布，不能只取消查询而永久丢失图钉。只重新采样，不回放位移或追加惯性；零位移与非法位移不应失效现有图钉。停止页面后，迟到的松手／原生地图回调不得重新启动查询，恢复页面时重新采样。
- 地图移动期间保留上一完整批次的照片图钉、封面和聚合数量，使用 `MKAnnotation` / `MKAnnotationView` 由 MapKit 原生定位、跟随相机与剔除屏外内容；不使用 SwiftUI 定时器手动定位或从屏幕点反算 GPS。聚合锚点必须是当前封面照片的真实拍摄坐标，不能使用平均经纬度或平均屏幕点冒充拍摄位置。旧视野的照片条、总数及查询仍立即失效，不能用保留图钉推算新视野总数。停稳后一次性用完整新批次替换图钉（包含空批次），隐藏照片集合改变或页面进入后台时清除保留图钉。
- 密集照片点显示照片封面加真实数量角标，单张只显示照片；聚合通过同一次原生投影确认的照片流生成，最多保留 20 × 12 个轻量单元，并合并相距不足 100 pt 的标记。超过 32 个展示组时保留数量最多的 32 组，其余分别合入最近的保留锚点，保留全部数量；不得在每次合并时重新穷举全体点对。最多同时请求 32 张图钉缩略图；胶片仅请求当页实际可见照片，不全库下载。连续视野计数通过任务 ID 管理 SQLite 游标，旧任务的结束／取消不得清理新任务的读取游标。

地图回看的近端按原生可达范围调整。主地球使用同一套近景照片查询、聚合与标注，并保留其指定城市范围。照片条空态、加载和失败使用 [主地球](globe.md) 的共享规则。
