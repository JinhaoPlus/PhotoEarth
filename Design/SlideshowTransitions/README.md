# Photo Earth 放映转场效果库

用浏览器打开同目录的 [交互预览](index.html)。五种效果共享一条从 0 到 1 的转场时间轴。可以直接切换效果、拖动检查中间帧，也可以看一段 13 页的放映。预览从工程里的公开样片读取图片，第二组三幅竖图使用预先确定的 9:16 样片构图。网页可以离线打开。

## 五种效果如何使用

| 效果 | 时长 | 用法 |
| --- | --- | --- |
| 柔和叠化 | 720 ms | 持住旧页，让完整的新页逐渐覆盖。连续拍摄、动态素材、跨日，以及地球镜头前后的照片衔接，优先使用叠化。 |
| 轻推入场 | 780 ms | 新照片在叠入时从完整适屏尺寸的 98.2% 回到 100%，落定后静止。示例中用在收藏的单张静态照片。 |
| 柔边揭幕 | 820 ms | 两页固定，一道半屏宽的渐变遮罩向右揭开新景。只在同站同日、时间拉开且两张单图方向一致时考虑。两张照片相隔至少 45 分钟。 |
| 背景先行 | 800 ms | 背景在前 65% 的时间内完成换色，前景从 20% 的位置开始叠化。用在横竖单图之间，让两侧留白和照片主体分两步交接。 |
| 拼图错拍 | 820 ms | 固定格线，从左向右每隔 85 ms 启动一格叠化，最后一格也在 820 ms 内结束。前后格数、格宽和位置一致且整页就绪时才用。 |

## 一段放映如何排列

- 把另外四种效果当作偶尔出现的变化。一次变化之后，至少经过两次普通叠化才能再次使用。即使素材全部收藏，轻推也要隔开至少六次其他转场。
- 在可以变化时，先看两页拼图能否对齐，再看横竖是否改变，然后看到访内的拍摄间隔，最后才看收藏标记。全景和极端比例也按适屏完整展示。触发条件不足时自然连续叠化。
- 预览先排好每个相邻页边界的效果。回看、暂停、翻页和重播都不重新抽签。示例的四次变化依次是收藏单张轻推、横转竖时背景先行、时间跳跃时柔边揭幕、同格拼图错拍。
- 手动翻页使用 160 ms 短叠化，连续按键以最后一次输入为准。减少动态效果时自动页使用 200 ms 短叠化。照片停留沿用单张 3.6 秒、双图 5 秒、三图 6.5 秒。暂停冻结时间轴和停留时钟。

## tvOS 原生实现

[编排器](../../PhotoEarth/Domain/Slideshow/SlideshowTransitionDirector.swift)根据两页实际成员、比例和拍摄时间选出效果。[播放协调器](../../PhotoEarth/Features/Slideshow/EarthSlideshowCoordinator.swift)等素材就绪，再启动转场时钟。入场完成后开始停留计时。

[媒体画布](../../PhotoEarth/Features/Slideshow/SlideshowTransitionCanvas.swift)用 UIKit 图层实现透明度、缩放、柔边遮罩和分格叠化。照片停稳后停止逐帧刷新。遥控器在转场中翻页时从当前画面衔接。暂停选片直接显示所选照片。日期、小地图和控制层独立于照片入场。

浏览器版本的[效果定义](effects.js)和[示例播放器](preview.js)用于逐帧比较。原生实播用例 `testAutomaticEffectsFollowTheResolvedPages` 使用项目里的公开样片，将每页停留缩短到 1.8 秒，保留正式转场时长，依次覆盖轻推、常规叠化、揭幕、背景先行、同格错拍和手动回看。
