## 如何读清单

- 每行保留原始 `place_id`、别名归并后的 `display_id`、地区、locale、实际显示名。按城市 ID 而不是照片坐标统计，文件只含公开地名。显示路径区分地区或语言首选、TSV 原字段、SQLite 字段、针对旧 TSV 原值的修复、英语字段及底表原名回退。英语字段本身有时保存的是当地拼写。八种基础语言中，653,591 行明确走英语、源名或已记录的日语原名回退，其中 1,562 行的同一写法也另获目标语佐证，其余 652,029 行缺目标语直接用例。
- JSON 另按目录所用国家和地区列出地点总数及各语言获佐证的条数。香港、澳门、台湾的显示语言结果另见上表。
- 目标语佐证按 Unicode NFC 后逐字核对。国家机构、官方地名表、GeoNames 有语言标记的现用异名、Natural Earth 对应语言字段、具备同一实体证据的 Wikidata 标签，以及列出出处的人工首选各有标记。多份资料可能有共同上游；同一个语言、地点组合只计一次。人工选择沿用当地原文且来源未证实目标语拼写时，只记原文佐证。
- `other_target_names` 逐一保留目标语资料中的其他写法与可回查 ID。异名、简称、市镇与城区的名称习惯都可能导致分歧，不能将这列直接解释为误译。Wikidata 身份冲突已拒绝转移译名，有 2,785 个有冲突的地点，候选与对应关联键仍可查。288 个语言与 ID 组合的 SQLite 原记录单独显示时与产品归并后的结果不同，两种写法及各自的佐证均可在该行查看。
- `exact_source_name_refs` 表明显示名与原始地名、当地行政资料或原文记录相同。GeoNames 的主名和 Natural Earth 的基本名可能是转写，不能仅凭字段名判定当地语言。中文另一地区的相同拼写、从其他中文来源进行的字形转换都保留标识。仅找到原名、英语、其他地区形式或未找到佐证的记录，仍缺该目标语直接证明。
- 清单前缀包括 `GN`（异名 ID/地名 ID/语言）、`GN-main`、`NE`（Natural Earth ID 和字段）、`WD`（Wikidata QID 和语言）、`IGN`、`Census`、`CN-registry`、`NAER`（台灣國家教育研究院表行号）、`UNGEGN`（城市、语言和名称类型）及 `review`（有出处的人工判断）。台湾国教院全量表只计作台湾直接证据。另经查核并写入通用繁体人工首选的多地用例，逐条列出原地区与来源。UNGEGN 保留其原始语种和本地名／异名。其罗马字转写只给原文提供证据，例如 Okayama 可佐证来源地名拼写，日语界面文字另对照「岡山市」。

法国市镇 Prévessin-Moëns（INSEE 01313）的英文显示沿用官方原文。Wikidata 的同一实体法语标签与 IGN 一致，英语标签却写成法国另一座市镇「villarodin Bourget」。清单保留这处冲突；产品显示仍为 Prévessin-Moëns。[Wikidata Q328385](https://www.wikidata.org/wiki/Q328385)
