# 放映

## 子功能

- 首页默认播放整个可见合格图库，也可多选本场旅程，照片墙播放打开时的固定范围。最近的旅程先播，每趟按实际到访顺序播放，每次到访内依拍摄时间播放入选照片。
- 国家墙播放该国的各站。城市墙播放整面墙的全部旅程，每趟只播本市的到访。页头的放映按钮与 Play/Pause 快捷入口使用同一范围。同一旅程中再次回到这座城市时以日期提示。打开播放控件后，左上角最多显示三段旅程，较长的刻线和白字标出当前段。前后还有旅程时刻度竖线向对应方向延伸，只有一段时收起刻度。
- 放映按页选片并对近似重复素材去重。静态照片按原构图播出；Live Photo 和短视频可播放动态画面。原声由观众为本场开启。
- 相邻竖图可组成双图、三图，或和一张横图并排。拼图显示共同日期与地点，单张显示精确时刻和小地图。转场以叠化为主，按前后两页的构图、拍摄间隔与收藏标记穿插轻量转场。长放映里偶尔会有宽幅横移、收藏照片退镜或从中央展开的拼图，停稳后可看完整构图。
- 显示控件时，播放栏下方的胶片用白框标出当前页的照片，随播放推进。退出后恢复来源页面和 Focus。
- 遥控器 Back 先关闭选曲页或控制层。在纯放映画面按 Back 暂停并询问是否退出，取消后恢复原来的播放或暂停状态。准备、失败或播完时按 Back 回到来源。

## 用户怎么进入

- 在首页选择「放映」，或在各照片墙选择「放映」。开场页默认准备推荐配乐，直接按「开始放映」即可，也可先换歌或关闭配乐。开场镜头与首批选片同时进行，镜头开始时出现第一站标题。
- 首页开场页点「选择旅程」，在左栏上下切换年份，向右勾选旅程。较长列表也可按国家或地区、城市和地名搜索缩小范围。批量勾选按钮标出当前筛选范围内的旅程段数，「已选」汇总各年份的选择。点「完成」回到开场页，再按「开始放映」。Back 放弃编辑，重播沿用本场选择。
- 中键展开控制层，高亮行标出当前旅程。「上一段旅程」和「下一段旅程」可跳到相邻旅程的开头，并保留播放或暂停状态。按 Play/Pause 暂停或继续，左右翻页。从播放栏向下进入胶片并暂停，向左或向右可滚过多屏，接近末端时继续准备后续照片，中键单张查看，继续播放从所选照片的下一张接上。Back 先收起控制层，再按一次可确认退出到来源。

## 各入口何时显示旅程刻度

本场有两段及以上时，刻度与播放控件同时出现。手动收起控件或播放中控件自动隐藏时，刻度同步收起。照片墙的「放映」按钮与遥控器 Play/Pause 使用同一个范围。

| 功能入口 | 放映范围与刻度 |
| --- | --- |
| 首页 → 放映 | 默认全部旅程，也可在开场页选几趟。选了两趟及以上就显示。 |
| 最近到访 → 某次到访的照片墙 | 本次到访。只有一段时收起。 |
| 地点 → 国家或地区 → 查看所有照片 | 各趟旅程在所选国家或地区的到访。两趟及以上显示。 |
| 地点 → 城市卡，或 Apple TV 主屏 Top Shelf → 城市海报 | 整面城市墙，每趟只播本市到访。两趟及以上显示。 |
| 首页城市卡或照片详情小地球 → 有指定城市的地球 → 照片墙 | 仍按指定城市播放，两趟及以上显示。改看当前画面时按冻结的地图画面确定。 |
| 滚动地球或地图回看 → 当前画面照片墙 | 中键圈定的实际地图画面。画面内素材跨两趟及以上就显示。 |
| 那年今日 → 放映这一天 | 所选月日在各年份的全部可见素材，按年份从近到远逐项播放。至少两个年份有素材时显示年份刻度。 |
| 免费预览 → 选一趟旅程 | 所选旅程。只有一段时收起。 |

## 容易验错的地方

- 照片墙成员可能多于本场选片，选片只影响本场。分别核对来源范围、选片和实际展示。删除、撤权或相册排除需影响正在展示和待播项。 [放映规则](../../rules/slideshow.md) · [播放协调器](../../PhotoEarth/Features/Slideshow/EarthSlideshowCoordinator.swift)
- 首张照片出现只证明开场。验长播还要经过分页、跳过暂不可用素材、退出释放和 Focus 恢复。 [近期模拟器验收](../LARGE_LIBRARY_PERFORMANCE_FIXES_2026-11-21.md) · [配乐](music.md)
