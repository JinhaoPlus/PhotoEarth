# 所有照片墙共用地图回看

2026-10-11：按用户要求把地图回看扩展到全部照片墙，统一复用最近到访已有的实现。本轮不安装 Apple TV 真机。

## 范围与交互

| 来源 | 初始镜头 | 回看中的照片范围 |
| --- | --- | --- |
| 最近到访 | 来源墙读取快照内该次访问的完整照片范围 | 当前地图画面内全部照片 |
| 国家 | 同一快照内该国家全部已固定地点成员的照片范围 | 当前地图画面内全部照片 |
| 分类城市、首页指定城市、照片地点探索 | 同一快照内该城市全部已固定地点成员的照片范围 | 当前地图画面内全部照片 |
| 滚动地球当前视野 | 来源冻结镜头的中心与距离，回看默认平面普通地图 | 当前地图画面内全部照片 |
| 回看自身的当前画面照片墙 | 直接返回已有地图 | 当前地图画面内全部照片 |

初始集合仅决定开场取景，不限制移动后的图钉、胶片或新圈定照片墙。这与最近到访当前已确认的行为一致。来源照片墙保持原有固定集合、数据库读取版本、加载页、滚动实例和最近照片焦点。

所有入口均使用 `MapReviewView`、`MapReviewCamera`、`MapReviewSession`：完整触摸面拖动、物理方向输入、Play/Pause 缩放 Dock、地图／卫星 switch、照片封面加聚合数字、移动期间保留原生图钉、准确视野计数、分页照片墙和详情。回看内部入口复用现有地图，避免递归叠加 MapKit 实例。

## 实现边界

- `ViewportPhotoWall.openMapReview` 改为必需的回调，所有调用点都有显式行为；来源快照未准备好时显示禁用入口。
- `MapReviewOrigin` 只传递固定地点 ID 与参考坐标，或冻结镜头中心与距离，不复制照片列表。
- 国家和城市初始取景通过 SQLite 临时成员表聚合，支持超过 SQLite 常规绑定数量的成员集合，不把第一访问或第一批 48 张当成完整范围。经度沿参考坐标展开，保留跨日期变更线的紧凑范围，封面仍使用真实 GPS。
- 沿用每批 512 条候选、每页 48 条记录、最多 240 个聚合单元、32 个展示图钉的预算，不增加全库缩略图或图片分析请求。
- 滚动地球来源墙的精确计数在回看期间暂停，关闭回看后继续；读取版本与冻结的原始地图不释放，回看使用独立相机。
- 继续遵守独立查询任务 ID 的 SQLite 游标清理规则，过期结束或取消不清理其他任务的游标。
- 国家页的「全部国家／查看全部照片」按钮加入与城市卡片共用的 Focus 记忆，关闭国家墙后恢复实际来源按钮；隐藏照片墙在共享组件内部也明确退出辅助功能树。UI 验证只查找当前启用的入口，避免把保留在原实例中的隐藏控件当成活动控件。

## 验证记录

相关单元测试最终通过：51 个测试，含参数展开共 60 次执行。覆盖完整成员初始范围、重复 ID、1,200 个额外成员 ID、跨日期变更线、排除封面、数据库更新后固定读取版本、独立回看相机、原生标注位置、分页与来源墙投影。

证据：`/tmp/photoearth-all-wall-review-unit-final.log`，读取结果为 `Test-PhotoEarth-2026.10.11_20-10-11-+0800.xcresult`。原有地图停稳测试的固定 1.2 秒等待改为有 8 秒上限的实际停稳条件；停止后迟到回调的检查仍等待完整防抖窗口，不改变产品的 850 ms 防抖。

第一轮 UI 测试遇到其他验证同时使用原模拟器，以及磁盘空间不足；中断该轮。后续使用单独创建的 4K tvOS 26.5 模拟器。隔离后确认国家页未记住头部来源按钮，已修复；回看内部墙的测试还需排除隐藏来源墙同名按钮，并处理没有放映入口的情况。
