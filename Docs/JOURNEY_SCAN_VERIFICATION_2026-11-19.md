# 旅途扫描与离线地名验证 · 2026-11-19

## 图库纳入与撤回

扫描以 Photos 当前生效的拍摄日期和坐标为准，先排除不可访问资产、所选普通相册成员、截图和录屏。其余有时间和 GPS 的照片或视频先进入地球。图片 TIFF 厂商或机型、原始视频的 QuickTime 厂商或机型用于确认拍摄设备。原件检查仅访问本机资源，串行读取，图片上限 2 MiB，单次时限 5 秒。证据不足保留为待确认。设置可恢复已确认缺少相机信息的素材。

相机结果按资产 ID、修改版本、媒体类型和判定规则版本存入本地 SQLite。界面可在相机深查之前使用元数据索引；正在展示的素材如被确认排除，会收到资产撤回通知。后续索引更新按已确认排除的变更序号处理。来自相册的重复资产在单批和跨批扫描都按 ID 去重，选中相册之间取并集。已消失的所选相册需要 Photos 持久变更记录确认删除，暂不可核实时阻止发布。设置可解除无法访问的旧选择。

快照中的检查时间横跨约 265 秒，已尝试 2,943 个素材。后续读取可能改变这些数量。账本保存检查时间和结论，因此这份快照无法区分原件仅在云端、超时、达到读取预算或文件缺少可判定元数据各有多少。待确认中的 Live Photo 共有 19,280 个，其中 1,888 个已经尝试读取。Live Photo 的标记只说明素材包含实况媒体；确定厂商或型号仍需实际相机字段。

LensPin 在读取原始资源前可通过 Photos 的非公开信息面板属性取得已缓存的厂商或型号。Photo Earth 的相机路径使用公开接口。tvOS 27 的公开 `PHAsset.extendedMetadata` 提供说明文字、原文件名和关键词，均无法直接确认机型。

视频读取规则第二版识别原始容器和轨道中的 QuickTime metadata、QuickTime user data 及公共厂商／型号字段。仅有拍摄镜头等字段、原件无法完整核对或存在未检查的定时元数据轨道时保留待确认。升级仅撤销第一版对视频做出的负面结论，并让这些视频重试。旧负面结论曾移除成员时，会重新核对轻量成员索引。照片、Live Photo 和已有的视频厂商／型号证据继续沿用。Mac 以单任务运行生产读取器和账本的隔离测试，3 项通过，包含实际生成的 QuickTime 用户数据、仅镜头及无标签原始 MOV。读取器、账本和测试同时通过 arm64 tvOS 26 目标的类型检查。[视频证据及迁移门禁](../PhotoEarthTests/VideoCameraEvidenceTests.swift)

## 离线地名

App 随包资源与 LensPin Cloudflare 清单的 SHA-256 一致。坐标匹配在设备上执行。更新仅下载公开清单和城市文件，检查长度、记录数和 SHA-256 后原子替换上个版本。原始访问按首张定位照片的坐标命名，相邻同城市身份的访问可跨长间隔归入同一旅途。「最近到访」保留原始访问。

2026-11-19 实际在 Mac 分别编译两项目的坐标匹配实现，用 28,096 行城市目录运行 1,246 个公开坐标，覆盖 8 种语言。对照的 9,968 个组合在城市身份、城市名称、国家名称、ISO 代码和匹配来源上均一致。[双代码对照脚本](../Scripts/verify_lenspin_city_parity.py)

## 实体电视相册门禁

`RealTVAlbumScopeTests/excludingOneReadableAlbumWithdrawsAndRestoresItsTravelPhotos()` 仅编入 tvOS 真机测试。测试进程显式设置 `PHOTOEARTH_REAL_TV_ALBUM_SCOPE=1` 才会执行。宿主使用 Debug 构建，并且 Photos 已授权。真机执行由当前电视验证任务统一调度。

门禁选用电视图库中一个可读、未被用户排除的普通相册。相册内外分别取最多 12 张已具备时间与定位的照片作为对照，使用 PhotoKit 实际成员计算期望集合。最多各取 2 张本机原件核对相机证据，沿用生产时限、字节上限、禁用网络和未知证据保留规则。三次发布均经过生产扫描决策、证据账本和 SQLite 索引，并经照片墙分页接口读回全部样本，核对 ID 集合及统计。日志只记录合计数量。

用户原有选择作为三阶段的基线。排除仅改变测试内的范围副本，三次发布都写入随机临时目录。成功和错误路径均清理测试数据，并检查真实设置的原值；整个门禁不向系统图库写入。若电视无符合条件的普通相册或缺少相册外对照，测试明确报出前置条件未满足。

实体 Apple TV 已验证三次发布的成员数依次为 16、12、16。[真机测试](../PhotoEarthTests/RealTVAlbumScopeTests.swift)


### 真机设置界面往返

在已经授权、已保存初始扫描范围的电视上，将 UI 测试 runner 环境设置为 `PHOTOEARTH_REAL_TV_ALBUM_UI=1`，单独执行 `PhotoEarthUITests/RealTVAlbumScopeUITests/testRealTVAlbumExclusionPersistsAndRestores`。冷启动后门禁等待上次准备完成，从原生侧边栏进入设置。它记录排除相册总数与相机筛选开关，只切换一个原本纳入、至少含一项素材的普通相册。每次保存后给大图库最多 450 秒重新准备，再次打开范围确认该相册、总数与开关。最后通过同一界面恢复最初的选项并读回。中间失败会尝试恢复。
