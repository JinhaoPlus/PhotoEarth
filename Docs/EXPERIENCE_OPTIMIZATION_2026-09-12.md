# Photo Earth 体验与规模优化实现（2026-09-12）

本轮按体验评审落实四项 P0，以及首次可浏览交接、光点视野预算和追加布局工作。目标是让范围可理解、照片可连续观看、大图库累计查询成本受控。保留原生 MapKit 纯卫星、同一全屏地图、实际 GPS、冻结投影、四层 Back 与系统本地化。

## 已落实

| 体验 | 实际变化 |
| --- | --- |
| 城市或当前画面 | 克制常驻范围提示；城市模式长按 Dock 中显式切换到当前画面；胶片在候选抽样前限定城市成员，再严格投影 |
| 预览状态 | 查找中、查询失败、无预览明确分开；无预览不表示整片区域没有照片 |
| 连续观看 | 纯照片入场，左右连续查看同一墙；48/49 边界按需加载，反向取消待翻页；Back 恢复最后观看照片 |
| 信息与地点 | 中键显示操作层；信息与拍摄地小地球继续可达，显式收起后回归完整构图；不定时移除 Focus |
| 首次生成 | 元数据原子提交即宣布可浏览，约 1.4 秒后进入地球；慢地名不阻挡。主动查看进度、暂停或辅助导航保留当前页 |
| 欢迎 | 使用现有中性 MapKit 地球，去掉装饰球和虚构个人光点 |
| 光点 | 按索引建立空间桶，停稳跨阈值重分配地理预算，最多 180 点、每 2° 网格最多 2 点；只做标记增删差量 |
| SQL | WAL 会话中稳定混合方向键分页；保留未消费候选；准确计数使用持续语句；城市成员表按会话建立 |
| 原生投影 | 约 3 ms 主线程时间片、精确 GPS 有限缓存；详情、分页及 Focus 优先；首批无匹配自动继续有界查找 |
| 图片 | 全页面实际请求统一本地 4／云端 2、去重、取消、超时和优先级；独立尺寸缓存；墙预览延续到详情；邻图仅有限本地预取 |
| 深翻与分类 | 增量维护行几何和位置字典；隐藏墙退订；分类封面与地名分别准备 |

新增文案进入 String Catalog 的全部 8 种现有语言。翻译工程完整性不等于母语审校已完成。

## 查询成本与边界

单次主机合成 SQL 核对：45,028 条矩形候选，OFFSET、混合键与持续游标三条路径返回完全相同的有序 ID 和 SHA-256；耗时分别约 2.850、1.276、0.043 秒。这仅覆盖 SQLite 候选遍历，不包括原生投影、PhotoKit、SwiftUI、内存峰值或电视硬件，也不是承诺 App 提速倍数。

证据：`.local-test-data/experience-review-2026-09-12/implemented-cursor-query-validation.json`。RTree 混合键分页仍使用临时排序；准确计数只准备一次语句。单地点查询使用 `(place_id, creation_date DESC, id ASC)` 索引，多个地点仍可能排序。任意跳到已过期检查点的兼容 API 仍可使用 OFFSET，正常连续浏览走键续读。

图片调度器缓存分档为缩略图 24 MiB、预览 64 MiB、单张近期详情 64 MiB，连同调度器在途预留上限 240 MiB；最多 64 个完成缓存条目。首页原有缓存和当前视图、PhotoKit、MapKit/GPU 仍有各自引用，因此这里不是进程内存上限。实际设备需测量内存高水位。

调试测量使用 `PhotoWall` 类别：`WallPageSelection`、`WallExactCount`、`WallProjectionSlice`、`WallCountSQLCursor`、`WallCountSQLBatch`。投影片段在让出执行前结束，计数／游标生命周期包含主动暂停；记录只有阶段、耗时与数量。

## 验证记录

验证产物集中于 `.local-test-data/experience-optimization-2026-09-12/`。采用显式公开示例／合成记录，没有重新扫描或修改用户图库。本轮未安装 Apple TV 真机。

- 最终完整 **276 项单元测试、35 个测试套件通过**；包含参数组合共 332 次执行，无失败或跳过。覆盖键续读同时间排序、剩余候选、计数取消／失效、旧地点可见性、城市抽样范围、扫描交接与后台恢复、48/49 连续浏览、追加行稳定、共享图片预算／去重／失效，以及首次权限状态。最终全绿结果包为 `UnitComplete.xcresult`，日志为 `unit-complete.log`。
- **10 条不同 UI 流程分轮通过**，设备为 Apple TV 4K 第三代 1080p、tvOS 26.5。城市限定拖动后显式切换当前画面、扫描暂停／继续／提前浏览、初扫交接与设置重建、详情 1→49→48 与 Back 恢复、国家详情／地球详情进入真实拍摄地、原生侧边栏、完整四层导航、混合比例墙翻到第 60 张再返回，以及欢迎页两个原生按钮与显式示例入口均有实际遥控器事件验证。
- UI 回归发现并修复了三项实际问题：深页详情返回时懒加载行未实例化而丢失 Focus；初扫地名工作后排队的重建仍显示旧扫描模式；前台权限检查将尚未询问的状态误当成拒绝，覆盖欢迎页。各自都有对应通过的回归证据。
- 1920×1080 截图复核了城市范围胶囊、雪地上的局部提示衬底、原生缩放 Dock、纯照片状态、详情操作／信息层、首页构图、分页前后原始比例，以及没有个人光点的中性欢迎地球。欢迎页文字、按钮、地球轮廓与法务署名均可见。截图目录及 `manifest.json` 保留测试名称映射；比例图是明确的合成验证图。
- `generic/platform=tvOS`、`Release`、`CODE_SIGNING_ALLOWED=NO` 最终构建通过，见 `release-final.log`。这是设备目标的无签名编译检查，不代表已签名、安装或实测设备性能。
- 新增 12 个 String Catalog key 的 8 语言覆盖和格式占位符一致性检查通过；`git diff --check` 通过。

结果包对应关系：`ExperienceUI.xcresult` 保留暂停／继续／提前浏览通过记录；`VerifiedUI.xcresult` 保留连续观看、两个详情地点分支与侧边栏通过记录；`FinalVerification.xcresult` 包含完整单元及城市范围、首次交接、四层导航通过记录。最后一包仍标记一次旧中文计数断言失败，原因是构建时测试源码尚未更新；更新后的 `RatioVerified.xcresult` 独立通过，并以实际到达第 60 张取代仅检查汇总计数作为分页证据。早期失败结果保留，不能把分轮验证表述为单个全绿结果包。
